# Fisherman's Horizon

拡大再生産型の漁業・ハンティング 3D ゲーム（Godot 4.6 / GDScript）。
企画書 `Fisherman's Horizon.docx` に基づく。粗末な漁船から始め、漁と狩りで資金と名声を稼ぎ、
近海の主・海賊を討ち、より強い船と武器を得て島々を進み、最後に人類種の天敵レヴィアタンを討伐して
伝説の漁場 Fisherman's Horizon を目指す。

## 起動
- `起動.bat` … ゲームをプレイ実行
- `エディタ起動.bat` … Godot エディタで開く
- Godot 本体: `C:\Users\aoe10\Downloads\Godot_v4.6.1-stable_win64.exe\Godot_v4.6.1-stable_win64.exe`

## 操作
| 入力 | 動作 |
|------|------|
| W / S | 前進 / 後進（低速・戦車的） |
| A / D | 左右旋回 |
| マウス | 視点・照準（船体と独立） |
| 左クリック | エイム武器（ガトリング/大砲/銛）射撃 |
| 右クリック | 魚雷（ロックオン追尾） |
| E（長押し） | 魚群に近づいて漁 |
| Esc | マウス開放／再キャプチャ |
| 港メニュー | 魚市場・酒場・造船所・航路・出港 |

## ゲームループ
出港 → 近海で漁（魚倉が減る）／主・海賊・モブと戦闘（装甲が減る）→
食料が尽きる前 or 魚倉が満ちたら帰港 → 魚市場で売却・酒場で賞金/遺産換金・造船所で船/武器更新 → 再出港。
名声が貯まると次の島が解放され、既知の島へはファストトラベル可能。

## 構成
```
project.godot          プロジェクト設定（入力マップ・オートロード）
scenes/World.tscn      メインシーン（薄い。実体は World.gd が構築）
scripts/
  GameState.gd  (autoload) 可変状態：資金/名声/船/装備/積荷/現在地
  Database.gd   (autoload) 静的データ：船/武器/魚/モンスター/島
  World.gd       全体統合・フェーズ管理・スポーン・武器発射
  Player.gd      自船（操船・三人称カメラ・エイム・衝角）
  Enemy.gd       主/戦闘モブ/海賊の共通実体（ビルボード）
  FishSchool.gd  魚群（ビルボード・漁）
  Island.gd      島・入港判定
  Projectile.gd  弾（ガトリング/大砲/銛/魚雷）
  HUD.gd         航海中UI（ソナー/食料/魚倉/装甲/武器/通知/照準）
  PortUI.gd      港メニュー（市場/酒場/造船所/航路/出港）
  TitleScreen.gd タイトル・勝利オーバーレイ
assets/images/   Codex生成の透過PNG（魚/モンスター/海賊船）
画像生成/         Codex image_gen 連携（プロンプトCSV＋ランナー＋透過処理）
```

## 画像生成（Codex 連携）
API 不要。デスクトップ版 Codex の組み込み `image_gen` を使用（`codex login` 済みが前提）。
```
cd 画像生成
bash 画像生成_codex.sh            # プロンプト.csv 全件（既存はスキップ）
bash 画像生成_codex.sh -f         # 全件上書き再生成
bash 画像生成_codex.sh fish_squid.png   # 指定のみ
python 透過処理.py                # 近白背景を透過してトリミング（生成時に自動実行）
```
生成画像は `assets/images/<種別>_<id>.png`（例 `fish_bonito.png`, `lord_hydra.png`, `pirate_corsair.png`）。
コード側はこの命名でテクスチャを読み込み、無ければ色付きプレースホルダで代替する。
